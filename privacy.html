プライバシーポリシー

最終更新日：2026年11月26日

1. 基本方針

CPA Study Hub（以下「本アプリ」）は、公認会計士試験や大学受験等の学習時間管理・答練成績分析および振り返りを支援するウェブアプリケーションです。本アプリはユーザーのプライバシーを尊重し、個人情報を適切に取り扱います。

2. 取得する情報と利用目的

本アプリは、ユーザーの同意に基づき Google OAuth 2.0 を通じて以下の情報へアクセスします。

  • Google アカウントの基本情報（氏名・メールアドレス・プロフィール画像）：ログイン状態の表示およびアカウント管理のために利用します。
  • Google ドライブおよび Google スプレッドシート（本アプリが作成したファイルのみ / drive.file スコープ）：ユーザー専用の学習記録スプレッドシート（Study Hub データ または CPA Study Hub データ 内の log / materials / exams / exam_results / exam_mistakes / config シート）および成績PDF用フォルダ（StudyHub_成績PDF または CPA答練PDF）の作成・読み書き・バックアップのために利用します。本アプリが作成していない他のドライブファイルにはアクセスしません。
  • Google カレンダーの予定情報（読み取り専用 / calendar.readonly スコープ）：学習予定時間の集計および「今日の勉強予定」の表示のために利用します。カレンダーの予定を作成・変更・削除することはありません。

3. データの保存場所、AI OCR 処理および第三者提供

  • 学習データ・設定の保存先：すべての学習記録・答練成績・誤答分析・設定（任意で入力するユーザー自身の Gemini API キーを含む）は、ユーザー自身のブラウザ（localStorage）およびユーザー自身の Google ドライブ内のスプレッドシートに保存されます。開発者のサーバーへこれらを永続保存することはありません。
  • AI OCR 解析（/api/ocr および Gemini API）：ユーザーが「PDF / 写真からOCR取込」または「成績表OCR＆誤答(A/B/C)分析」を実行した場合のみ、選択された成績表の画像・PDFデータを本アプリのサーバーレス関数（Vercel /api/ocr）またはユーザー自身の API キー経由で Google Gemini API へ一時送信し、点数・問題番号・正答率を抽出します。送信された画像・PDFおよび解析結果は開発者のサーバーには一切保存されず、応答完了後に破棄されます。
  • ユーザーの同意なく、取得したデータを第三者へ販売・提供・共有することはありません。
  • 「ChatGPTに送る」「Geminiに送る」機能は、ユーザーが明示的にボタンを押した場合のみ、学習サマリー・診断結果テキストをクリップボードへコピーまたは外部AI画面へ引き渡します。

4. Google API サービスのユーザーデータポリシー（Limited Use）への準拠

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、制限付き使用（Limited Use）の要件を含め、 Google API サービスのユーザーデータに関するポリシー（Google API Services User Data Policy） に準拠します。本アプリは Google ユーザーデータを広告配信や汎用 AI・機械学習モデルの学習に利用することはありません。

5. データの削除および連携解除

ユーザーはいつでも以下の方法で本アプリとの連携解除およびデータ削除を行えます。

  • 本アプリ内の「Googleアカウント管理」画面から「ログアウト」を実行する。
  • Google アカウントのサードパーティ アクセス管理ページから本アプリのアクセス権限を取り消す。
  • Google ドライブ上の「Study Hub データ（または CPA Study Hub データ）」スプレッドシートおよび「StudyHub_成績PDF（または CPA答練PDF）」フォルダを削除する。

6. プライバシーポリシーの変更

本ポリシーは必要に応じて改定することがあります。重要な変更がある場合は本ページ上でお知らせします。
